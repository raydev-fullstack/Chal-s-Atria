## 💼 Sobre o Projeto

Esta é a landing page oficial dos Chalés Atria, desenvolvida para apresentar 
a oportunidade de investimento a clientes e investidores interessados em 
adquirir chalés prontos para gerar renda passiva através de plataformas 
de hospedagem como o Airbnb.

O site foi criado com foco em conversão, apresentando de forma clara e 
atrativa os diferenciais do empreendimento, retorno sobre investimento 
e todo o potencial de lucratividade do negócio.

## 🏘️ Sobre os Chalés Atria

Os Chalés Atria são unidades desenvolvidas estrategicamente para o 
mercado de hospedagem por temporada. O investidor adquire seu chalé 
e passa a gerar receita com locações no Airbnb, unindo valorização 
imobiliária com renda recorrente.

Uma oportunidade sólida para quem busca:
- 📈 Renda passiva com hospedagem por temporada
- 🏠 Valorização imobiliária
- ✅ Negócio estruturado e pronto para operar
- 🌿 Empreendimento em localização privilegiada
